# Documentation checklist

- Write documentation and CI diagnostics in English (CLAUDE.md, Git etiquette).
- Keep README.md as the outward-facing summary; keep package-selection rationale in one place (CLAUDE.md, What this repo is).
- Preserve meaning; verify behavior against the current repository and flag unverified claims.
- Check links, file paths, cross-references, duplication, and obsolete content.
